Из монолита выделены сервисы:
user-service — управление пользователями
request-service — управление запросами на участие в событиях
comment-service — управление комментариями к событиям
event-service — управление событиями, категориями и подборками

Для взаимодействия используется FeignClient.
Сервис обнаружения на порту 8761. У остальных сервисов порт случайный.

Добавлены сервисы.
Задачи **Collector**:
Принимать сообщения о действиях пользователей, используя gRPC. Записывать полученные данные в Kafka-топик
**stats.user-actions.v1** для дальнейшей обработки.

Задачи **Aggregator**:
Читать данные из топика **stats.user-actions.v1** и выполнять следующие вычисления:
a. рассчитывать сходство мероприятий и записывать результаты в топик **stats.events-similarity.v1**.

Задачи Analyzer:
Читать данные из топиков:
a. **stats.user-actions.v1** — для хранения информации о последней оценке (максимальном весе действия) пользователей
мероприятий;
b. **stats.events-similarity.v1** — для хранения информации о сходстве мероприятий.
Обновлять базу данных на основе поступающих данных.
Обрабатывать запросы от других сервисов по gRPC и предоставлять:
a. список рекомендуемых мероприятий для конкретного пользователя на основе сходства мероприятий;
b. список мероприятий, которые похожи на указанное и с которыми пользователь ещё не взаимодействовал.
