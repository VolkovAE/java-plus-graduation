Из монолита выделены сервисы:
user-service — управление пользователями
request-service — управление запросами на участие в событиях
comment-service — управление комментариями к событиям
event-service — управление событиями, категориями и подборками

Для взаимодействия используется FeignClient.
Сервис обнаружения на порту 8761. У остальных сервисов порт случайный.
